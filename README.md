## 🧩 Project Overview  

The **Sentiment Predictor** is a web-based application built using **Streamlit** and **Machine Learning (SVM Classifier)**.  
It predicts whether a given text expresses a **positive**, **negative**, or **neutral** sentiment.  

This project showcases how Natural Language Processing (NLP) and Machine Learning can be combined to create a real-time text sentiment analysis tool.

---

## 🧠 Model Information

| Feature | Description |
|----------|-------------|
| **Algorithm** | Support Vector Machine (SVM) |
| **Vectorizer** | TF-IDF (Term Frequency – Inverse Document Frequency) |
| **Evaluation Metric** | F1-Score |
| **Best Model Performance** | F1 = **0.772** |
| **Languages Supported** | English |
| **Deployment** | Streamlit Cloud |

## ⚙️ How to Run Locally

To run this app on your own system:

```bash
# 1️⃣ Clone the repository
git clone https://github.com/AkhileshS9899/Sentiment-Analysis.git

# 2️⃣ Navigate into the folder
cd Sentiment-Analysis

# 3️⃣ Install dependencies
pip install -r requirements.txt

# 4️⃣ Run the Streamlit app
streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`
